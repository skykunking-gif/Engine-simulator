# V8 エンジンシミュレーター

GM LS3(6.2L、90° クロスプレーン V8)をモデルにした、ブラウザで動く 3D エンジンシミュレーターです。クランクシャフト、ピストン、コンロッド、OHV 動弁系、燃焼ガスを、すべて同じクランク角に合わせて動かしています。

`index.html` 1ファイルだけで動きます。three.js r128 は CDN から読み込みます。

## 機能

- 回転数を 600〜6,600 r/min で変更
- 再生速度を 1/200・1/50・1/10・実時間で切り替え
- 一時停止と 15° ずつのコマ送り
- 視点プリセット(斜め・正面・側面・上面)とマウス操作での視点変更
- 気筒ごとの行程マップ、点火順序表示、720° 行程タイミング図(バルブリフト曲線付き)
- タコメーター
- 合成エンジン音(左右バンクを左右チャンネルに振り分け)
- ブロック、ヘッド、動弁系、燃焼ガス、気筒番号の表示切り替え

## 操作

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | 視点を回転 |
| 右ドラッグ | 視点を移動 |
| ホイール | ズーム |
| Space | 再生 / 一時停止 |
| → | 15° 送る |

## 諸元

| 項目 | 値 |
| --- | --- |
| 排気量 | 6,162 cc |
| ボア × ストローク | 103.25 × 92.0 mm |
| コンロッド長 | 154.9 mm |
| ボアピッチ | 111.8 mm |
| バンク角 | 90° |
| クランク | クロスプレーン(0 / 90 / 270 / 180°) |
| 点火順序 | 1-8-7-2-6-5-4-3 |
| 動弁 | OHV 2 バルブ / ロッカー比 1.7 |
| 圧縮比 | 10.7 : 1 |

寸法は GM LS3 の公表値に基づいています。バルブタイミングと動弁系の形状は、説明用に簡略化しています。

## 実行方法

`index.html` をブラウザで開くだけで動きます。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチの `/ (root)` を選んでください。
