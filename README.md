# エンジンシミュレーター

ブラウザで動く 3D エンジンシミュレーター集です(V6・V8・V10)。クランクシャフト、ピストン、コンロッド、動弁系、燃焼ガスを、すべて同じクランク角に合わせて動かしています。three.js r128 を CDN から読み込み、各エンジンは HTML 1ファイルで完結しています。

| ページ | モデル | 構成 |
| --- | --- | --- |
| [`v6/`](v6/index.html) | Nissan VR38DETT 3.8L | 60° V6 ツインターボ / スプリットピン 120° 等間隔点火 / DOHC 4バルブ / 点火順序 1-2-3-4-5-6 |
| [`v8/`](v8/index.html) | GM LS3 6.2L | 90° V8 / クロスプレーン / OHV 2バルブ / 点火順序 1-8-7-2-6-5-4-3 |
| [`v10/`](v10/index.html) | Lexus 1LR-GUE 4.8L | 72° V10 / 5ピン等間隔点火 / DOHC 4バルブ / 点火順序 1-6-5-10-2-7-3-8-4-9 |

ルートの `index.html` は、各エンジンへのリンクを並べたトップページです。

## 共通の機能

- 回転数の変更(V6: 700〜7,100 r/min、V8: 600〜6,600 r/min、V10: 900〜9,500 r/min)
- 再生速度を 1/200・1/50・1/10・実時間で切り替え
- 一時停止とコマ送り(V6: 20°、V8: 15°、V10: 18°)
- 視点プリセット(斜め・正面・側面・上面)とマウス操作での視点変更
- 気筒ごとの行程マップ、点火順序表示、720° 行程タイミング図(バルブリフト曲線付き)
- タコメーター
- 合成エンジン音(左右バンクを左右チャンネルに振り分け)
- ブロック、ヘッド、動弁系、燃焼ガス、気筒番号の表示切り替え

## 操作

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | 視点を回転 |
| 右ドラッグ | 視点を移動 |
| ホイール | ズーム |
| Space | 再生 / 一時停止 |
| → | コマ送り |

## 実行方法

`index.html` をブラウザで開くと動きます。GitHub Pages で公開する場合は、Settings → Pages で `main` ブランチの `/ (root)` を選んでください。
